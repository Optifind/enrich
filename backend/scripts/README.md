# Scripts

This folder contains single use scripts that can be used for data manipulation etc. This is not something that will be used in production environment. This differs a bit from the [Go project structure repo](https://github.com/golang-standards/project-layout/tree/master/scripts) but this might be a good way of structuring our repo. We might want to change this later.

All continuously running programs such as servers should be placed under `/cmd`.
