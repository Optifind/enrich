# `build/`

`build/` is meant for storing code and scripts related to the building of the app. The directory should mostly contain subdirectories that handle the building of specific parts of the app. This includes things like Dockerfiles etc.

In our case `build/` doesn't contain anything that deals with the runtime usage or deployment of the app. This can be found under `deploy/`.

## `build/api/`

`build/api` contains code and scripts related to the building of the product api.
